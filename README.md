HEART & DIAPHRAGM PUMP - QR WEBSITE
===================================
FILES
- index.html : mobile-friendly educational webpage with both looping GIFs and six explanations each
- qr-maker.html : creates a QR code after you have a public URL

HOST FREE WITH GITHUB PAGES
1. Create a public GitHub repository, e.g. heart-pump.
2. Upload index.html (and optionally qr-maker.html) to its root.
3. Open repository Settings > Pages.
4. Under Build and deployment choose Deploy from a branch, main, / (root), then Save.
5. Wait for GitHub to publish. Copy the public HTTPS Pages URL.
6. Open qr-maker.html in a browser, paste your public website URL, click Generate QR code, then Download QR as PNG.
7. Scan the downloaded QR using a phone and confirm the correct webpage opens.

NOTES
- The included GIFs load live from Wikimedia Commons. The site needs an internet connection.
- The reference Google Share links could not be opened, so similar CC-licensed Wikimedia animations are used.
- Wikimedia Commons source and attribution links appear in the footer.
- A QR code cannot reliably link to a local file on your computer: a publicly accessible HTTPS site is required for normal phone scanning.
